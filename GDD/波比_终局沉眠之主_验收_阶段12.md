## 1. 多阶段 Boss（GDD 7）

- **HP 800**（初值，`[PLACEHOLDER]`）。阈值 66% / 34% 切阶段。
- **P1 苏醒**：`swipe`（冲刺横扫，红框+方向箭头预警）+ `dreamOrb`（扇形梦境弹投射，朝玩家方向 spread）。
- **P2 寂瘴同化**：新增 `blightRing`（扩张瘴环，**长按 L 听声揭示安全缝**；不揭示时段为完整环，需记忆缝隙）+ `summon`（召唤回响）+ 场上出现 `blightZones` 瘴区（逐帧掉血，苔语项圈减伤生效）。
- **P3 终焉**：全招式 + `enrage`（提速 ×1.25、加伤 +1），收尾提速。
- **难度自适应（接阶段9）**：`tier = Σ 已解锁元进度等级` → `hpBonus = tier×70`，`cdMult = max(0.65, 1 + tier×(-0.04))`。元进度越高，Boss 越肉、出招越密。

## 2. 结局分支（探索即叙事，少对话）

击败后 `decideEnding()` 综合三输入：

| 输入 | 来源 |
|---|---|
| 探索完成度 | `balance.regionsMap` 除「寂灭之眼」外所有节点 `profile.regions[id] ≥ 100` |
| 是否回收全部灵影 | `!profile.everLostShade`（任何一次死亡遗弃灵影即置 false） |
| 项圈流派 | `collarStyle`：`warrior`(仅利爪) / `guardian`(九命/苔语) / `balanced` |

分支优先级：
- **slumber 安眠（真结局）**：探索全满 **且** 灵影全回收 → 绒光升起、主阖眼，环境转暖。
- **flame 燎原**：项圈流派为 `warrior` → 爪尖之火焚尽寂瘴，环境转赤。
- **silence 寂灭**：其余（曾遗弃灵影 / 守护或均衡流派且未全探索）→ 绒光逐盏暗下，环境转静。

演出为 `playEnding()`：相机闪光定调 + 3 行环境短句（serif，逐句淡入），无对话框。

## 3. 周目重组（接阶段9 种子）

- 首进固定种子 `lord-first`（可学习/可测）。
- 已通关（`bossesDefeated` 含 `lord`）或按 `F` → 新种子；`buildLordCfg()` 抖动阶段阈值 ±3% + 打乱各阶段招式顺序（同 seed 必产同一布局）。
- `R` 同种子重战。元进度奖励（绒毛/小鱼干）按阶段9 首杀/重复规则发放。
