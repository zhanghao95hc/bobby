## 死锁兜底逻辑（重点）

经济死锁在 GDD 5.3 单列为"灵毛死锁"，本实现用三层兜底彻底堵死：

1. **实体唯一 + 毛量叠加（防无限叠加实体）**
   场景只持有一个 `this.shade`。玩家在灵影处再次死亡时，旧灵影毛量并入新灵影并销毁旧实体，**绝不生成第二个灵影**。
   → 杜绝"反复死亡 → 满屏灵影 → 地图塞死/经济溢出"。

2. **远程赎罪（防卡不可达）**
   灵影生成在死亡点；若死亡点在瘴区/深渊等不可达处（阶段7 会强制生成在外缘），玩家仍可花小鱼干远程回收毛。
   → 杜绝"灵影永远拿不回 → 永远缺毛放不出技 → 劝退"。

3. **回收溢出丢弃（防突破 pool cap）**
   回收/赎罪时 `gained = min(cap - motes, carried)`，超出上限部分直接丢弃。
   → 杜绝"回收瞬间灌爆灵毛池 → 破坏后续经济曲线"。

> 注：小鱼干为永久货币，死亡保留，不进灵影（GDD 5.1 三层模型）。死亡惩罚**只**落在灵毛上，符合"死亡是节奏不是惩罚(P3)"。

## 验证动线（战斗沙盒）

```
[起手] 打 3 只小怪：每击灵毛+1、击杀灵毛+3 + 小鱼干+2 → 池满(33)后停止累积
[作死] 站着被怪摸死(HP 5→0) → 死亡点生成紫色灵影(携当前毛) → 700ms 后在猫窝标记处重生
[回收] 走回去爪击灵影(HP 4) → 灵毛返还池中（溢出部分丢弃，HUD 提示）
[兜底] 若灵影卡住 → 按 B 花小鱼干远程赎罪
[再死] 灵影未回收时又死 → 新灵影吸收旧灵影毛量（数值叠加，实体仍唯一）
```

