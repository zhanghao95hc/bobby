# 波比 (BOBBY) — 阶段10 验收：整体 HUD/UI + 反差萌引导 + 死亡柔化 + 解锁式地图

> 参考 GDD 第6节（新手引导）+ 整体 UI 基调（反差萌：软萌壳 + 沉重内核）
> 引擎：HTML5 + Phaser 3（CDN，无构建）。所有数值走 `data/balance.json`。

## 一、交付清单（对照用户 4 条要求）

### 1. HUD（鱼心 / 灵毛池 / 小鱼干 / 项圈槽 / 区域名）
文件：`src/ui/Hud.js`（重写）
- 左上**圆角柔色面板**（反差萌壳：淡紫描边 + 半透明深底）+ **小猫 mascot**（波比吉祥物）。
- 面板内信息一眼可读：
  - `鱼心 ♥♥♥♡♡ 3.0/5` —— HP（珊瑚色鱼心，附数值读数，瘴区小数连续可见）
  - `灵毛 12/33` —— 旁附**进度条**（蓝青填充，池上限来自元进度 `motePoolMax`）
  - `小鱼干 48` —— 金色
  - `项圈 利爪/静默 (2/3)` —— 当前项圈槽占用
  - 顶部居中**区域名横幅** `区域 · 绒毛巢`
- 右上保留**解锁式区域图**（`setRegions`）。
- 占位美术，但布局清晰、对齐固定（scrollFactor 0）。

### 2. 引导流（GDD 第6节 6 项清单，首局推进）
文件：`src/scenes/FuzzNestScene.js` + `src/systems/Save.js`
- 6 项进度持久化在 `profile.onboarding{claw,pogo,listen,explore,hook,shade}`，**猫窝菜单显示 ✓/○ 清单**。
- 逐项落地：
  | # | 清单项 | 触发 | 状态 |
  |---|--------|------|------|
  | 1 | 30秒内给核心动词 | 起点粉绒球，提示爪击（必中零伤） | ✓ onboarding.claw |
  | 2 | 教程第一段零死亡 | 绒毛巢无真伤敌人；灵影教学为**安全模拟** | ✓ |
  | 3 | 低代价引入新机制 | 下扑(pogo)浅坑练习 + 听声暗道引导 | ✓ pogo/listen |
  | 4 | 机制靠探索发现 | x=1400 隐藏鱼堆，不靠文字 | ✓ explore |
  | 5 | 首局结尾留钩子 | 首次回窝 → 猫神低吼 + 点亮「沉眠回廊」 | ✓ hook |
  | 6 | 首次死亡灵影教学 | 「记忆残响」台按 E 安全模拟死亡→灵影→爪击回收 | ✓ shade |
- 位置化情境提示（`updateHint`）自然串联 6 项顺序。

### 3. 死亡界面（显示灵影位置 + 赎罪提示，弱化挫败）
文件：`src/ui/Hud.js` `showDeath()` + 各战斗场景 `onPlayerDeath`
- 柔化层：半透明深底 + 淡紫面板，文案**软壳裹硬核**：
  - 标题「波比睡着了…」（教学变体「波比打了个盹…」）
  - 「灵影替你把没花完的灵毛收好了」
  - `灵影在<左/右>边约 N 米处 · 携 <carried> 灵毛`
  - `走回去轻轻一爪就能唤回它 · 嫌远就按 B 在猫窝远程赎罪（约 X 小鱼干）`
  - 页脚「—— 死亡不是终点，是绒光的低语 ——」
- 接在 `CombatTestScene / BossScene / TempleScene` 真实死亡后，及 `FuzzNest` 教学模拟死亡后。
- 契合「死亡是节奏，不是惩罚」（P3）：小鱼干永久保留，灵影可回收。

### 4. 地图（解锁式区域图，首局结束点亮新区域）
文件：`src/ui/MapView.js`（新增）+ `data/balance.json` `regionsMap`
- `regionsMap.nodes`：绒毛巢 → 沉眠回廊 → 寂瘴沼 → 猫神殿 → 寂灭之眼（含连线坐标）。
- **MapView 浮层**：从猫窝菜单「查看区域地图」进入（Q/Esc 关闭），按 `profile.regions[id]>=100` 点亮节点、连线、高亮「你在这里」。
- 首局钩子点亮「沉眠回廊」后，MapView 中该节点即点亮——接阶段4钩子。
- 主世界（绒毛巢）固定不变，地图记忆不受影响（P2）。

## 四、实测路径（开 http://127.0.0.1:8088）
1. **HUD**：进任意场景看左上面板（鱼心/灵毛条/小鱼干/项圈/区域名）。
2. **引导 6 项**：绒毛巢按提示走——爪击绒球→pogo 假人→长按 L 听声显暗道→乱扑发现隐藏鱼堆→走到猫窝按 E（钩子点亮沉眠回廊）→走到 x≈1750「记忆残响」按 E 触发灵影教学→爪击灵影完成。猫窝菜单看 ✓ 清单。
3. **死亡柔化**：去 `B` 打锈齿鼠王送死，或 `C` 战斗沙盒被摸死 → 看柔化死亡层（灵影方向/携带量/赎罪提示）。
4. **地图**：猫窝菜单「查看区域地图」→ 看节点点亮（沉眠回廊已亮）。
