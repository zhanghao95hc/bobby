## 2. 元进度树（数据化）

定义在 `data/balance.json → metaTree`，每个节点字段：

```
name / desc       显示名与说明
cost              每级花费（随等级 ×rank 递增）
effect            结算类型：collarNotch(槽位+) / motePoolMax(灵毛池+) / moveSkill(移动技)
bonus             增量（collarNotch=1槽 / motePoolMax=12池）
skill             移动技 id（moveSkill 用）：doublepounce / glide
maxRank           可叠等级
requires          前置节点 id[]（未解锁则置灰）
```

当前 5 节点：

| id | 名称 | 花费 | 效果 | 前置 |
|----|------|------|------|------|
| notch1 | 项圈槽 +1 | 2 | 槽位 +1 | — |
| notch2 | 项圈槽 +1（进阶） | 4 | 槽位 +1 | notch1 |
| pool1 | 灵毛池 +12 | 2（可叠2级） | 灵毛上限 +12/级 | — |
| move_doublepounce | 二段扑 | 3 | 移动技（空中可再扑一次） | — |
| move_glide | 绒羽滑翔 | 5 | 移动技（空中长按跳/上缓降） | move_doublepounce |

解析链：`MetaProgress.resolve(profile,balance)` → `{notchBonus, poolBonus, skills, motePoolMax, collarNotches}`；
`applyToDerived()` / `applyNotches()` 把树折算进 `derived` 与 `CollarSystem.notches`，再传给 `Player`（读 `d.airPounces` / `d.glide`）。

> 所有数值走 balance.json，无硬编码；新增节点只需在 `metaTree` 加一条，AltarScene 自动渲染。

## 3. 记忆绒毛来源与消费

**来源（掉落）**
- Boss 首杀（锈齿鼠王）：`fluff +1`（记入 `profile.bossesDefeated`）。
- 里程碑：首次抵达猫窝（完成教学区探索）：`fluff +1`（记入 `profile.milestones`，仅一次）。
- 重组周目重复击杀 Boss：**不再掉绒毛**，改掉小鱼干（基础 25 + 额外 25）。

**消费（祭坛）**
- 按 `M` 进猫神祭坛 → 键盘菜单选节点 → 花费绒毛解锁 → 即时 `Save.save` 持久化。
- 返回主世界（T）即生效：槽位/灵毛池上限变化立刻反映，移动技立即可用。

## 4. 操作 / 入口键（阶段9 新增）

| 键 | 作用 |
|----|------|
| **M** | 猫神祭坛（花绒毛解锁元进度） |
| **N** | 猫神殿（重组挑战区） |
| **H** | 寂瘴潮（重组挑战区·瘴模式） |
| T | 返回教学区 / 在 Temple 内 = 同种子重进复现 |
| R | 在 Temple 内 = 新随机种子重组 |
| F | 在 Temple 内 = 同种子复现（调试） |
| K（空中） | 有二段扑元进度时，空中再按一次 = 二段扑 |
| 空中长按 跳/上 | 有滑翔元进度时 = 缓降 |

> 其余沿用：A/D 移动、空格跳、J 爪击(空中=下扑)、L 听声、E 猫窝/商店、I 项圈、B 小Boss。

## 5. 肉鸽重组（猫神殿 / 寂瘴潮）

`src/scenes/TempleScene.js`：进房用 `Rng(seed)` 程序化生成——
- 平台（5–8 块，随机位/尺寸）
- 敌人（3–6 只，随机地面点）
- 宝箱（1–2，给灵毛+小鱼干）
- 终点旗（右侧，触碰通关，本局小鱼干存入存档）
- 寂瘴潮模式额外叠加 1–2 个瘴区（Blight 系统：掉血/压听声/增敌）

**主世界固定**：绒毛巢（FuzzNest）布局写死，不进重组逻辑，地图记忆不受影响（符合 GDD P2）。

**重组触发**：每次从 FuzzNest 按 N/H 进入 = 新随机种子 → 布局重组。场内在 Temple 按 R = 强制新种子重组。

## 6. 种子化可复现（调试）

- `Rng.js`：mulberry32，支持数字/字符串种子（字符串走 fnv1a 散列），同种子必产同序列。
- TempleScene 顶部常驻显示 `种子 #xxxx`（如 `种子 #12488213`）。
- 复现步骤：记下令牌数字 → 在 Temple 内按 **F** → 用**同一 seed** 重进 → 平台/敌人/宝箱位置完全一致，可定位布局 bug。
- 数值平衡时也可直接在 `init({mode, seed})` 传入固定种子做 A/B 对照。
