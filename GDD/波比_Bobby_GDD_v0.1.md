# 波比 (BOBBY) — 游戏设计文档 (GDD) v0.1

> 类型：银河恶魔城 (Metroidvania) × 元进度肉鸽 (Meta-Progression Roguelike)
> 基调：反差萌（软萌折耳蓝猫外壳 / 失落猫神文明的黑暗内核）
> 核心战斗：近战爪击为主
> 版本：v0.1 — 初稿，数值均为假设，标注 `[PLACEHOLDER]` 待实测
> 作者：GameDesigner

---

## 0. 一句话定位

**一只娇小软萌的折耳蓝猫，在衰败的"绒光猫国"遗迹里，用爪牙与九条命的韧劲，撕开一段被遗忘的黑暗往事。**

设计目标：让玩家在"这也太可爱了吧"和"这世界怎么这么狠"之间反复横跳——这就是反差萌的核心张力。

---

## 1. 设计支柱 (Design Pillars)

所有后续机制、数值、关卡决策都以此 5 条为准绳，违反任意一条需重新论证。

| # | 支柱 | 含义 | 验收信号 |
|---|------|------|----------|
| P1 | **娇小之躯，凶悍之魂** | 玩家操控的是"看起来毫无威胁的小猫"，但机制要让他感到"我其实很能打、很聪明" | 玩家主动用可爱外形做诱敌/潜行；战斗后有"以小博大"的爽感 |
| P2 | **探索即叙事** | 黑暗内核完全靠环境、遗迹、敌人形态讲，不靠对话 dump | 玩家能凭场景推断出世界背景；无过场长文 |
| P3 | **死亡是节奏，不是惩罚** | 元进度肉鸽：死亡回猫窝，丢失"局内灵毛"，但探索进度/技能永久保留 | 死亡后玩家想"再来一局"而非"弃游"；重进挑战区会重组 |
| P4 | **反差张力** | 软萌美术 + 沉重风险。机制要主动玩这个反差（看似玩具的敌人会秒你） | 玩家表情在"aww"和"what the hell"之间切换 |
| P5 | **爪痕式风险换奖励** | 每个系统都给一个真实抉择：再深一点（更多战利品/更高风险）vs 收手回窝 | 玩家在"再走一步"和"回窝存钱"间犹豫 |

## 2. 世界观与基调（反差萌的核心）

- **绒光猫国 (The Downlight Kingdom)**：曾由九尊猫神统治的璀璨文明，以"灵毛"为能量。某日"寂瘴 (Silence Blight)"侵蚀，猫神相继沉眠/腐化，文明崩塌。
- **波比 (Bobby)**：一只走失的折耳蓝猫，循着微弱的灵毛气息闯入遗迹。它不知道自己为何而来——但玩家会逐渐发现，波比与某位猫神有渊源（留作叙事钩子，v0.1 不展开）。
- **反差落地**：场景是哥特废墟、腐化神像、凄美配乐；波比是圆润蓝灰、折耳、大眼。UI、受击音效、拾取反馈都偏"软"，但死亡、Boss、寂瘴偏"硬"。

## 3. 核心循环 (Core Loop)

### Moment-to-Moment (0–30 秒)
- **Action**：波比在房间内移动，发现敌人/可破坏物/隐藏缝，扑上去爪击或下扑
- **Feedback**：爪击命中 → 微小粒子 + 软"噗"音 + 极轻屏震；灵毛 +1 飘入；击杀有短促"喵呜"尾音
- **Reward**：灵毛（局内资源）+ 小鱼干（金钱）+ 探索发现的即时满足

### Session Loop (5–30 分钟)
- **Goal**：从猫窝出发，穿越一个区域 → 击败小 Boss / 抵达新猫窝 / 习得新能力 → 带着战利品回窝或死在路上
- **Tension**：HP（鱼心）有限 + 灵毛若死亡会掉落成"灵影"需回收 + 再深一步收益更高但寂瘴/敌人更强
- **Resolution**：
  - 成功回窝：存下小鱼干与记忆绒毛，区域进度永久保留
  - 死亡：在死亡点生成"灵影"携带未消耗灵毛；回猫窝重生，需回去 reclaim；探索进度不丢

### Long-Term Loop (数小时–数周)
- **Progression**：永久能力解锁（折耳听声、二段扑、绒盾等）→ 地图完成度 → 记忆绒毛驱动的元升级树
- **Retention Hook**：
  - 每日/每次重进时，部分挑战区与 Boss 房**程序化重组**（肉鸽要素），老玩家也有新鲜感
  - 季节/周常"寂瘴潮"：限时区域，掉率翻倍但难度飙升
  - 社交：最快通关路线、最少死亡纪录（可选排行榜，v0.1 不强制）

## 4. 关键机制规格 (Mechanic Specifications)

### 4.1 爪击 (Claw Slash)
- **Purpose**：核心近战输出与灵毛来源
- **Player Fantasy**：小猫一爪撕开敌人
- **Input**：攻击键（短按 = 地面横扫；空中按 = 下扑 dive）
- **Output**：对前方扇形造成 1 伤害单位；命中生成灵毛；空中下扑可踩敌弹跳（pogo 式位移）
- **Success Condition**：手感"脆、快、有反馈"，连击不卡顿
- **Failure State**：攻击后摇过长导致被反打；范围太大学生无压力
- **Edge Cases**：
  - 同时命中多个敌人 → 每个都结算灵毛（鼓励群攻走位）
  - 贴脸墙角 → 扇形被墙截断，伤害仍结算但不位移
- **Tuning Levers**：基础伤害、攻击前摇/后摇帧、扇形角度与距离、pogo 弹跳高度
- **Dependencies**：灵毛系统、敌人受击系统、下扑

### 4.2 扑袭 / 下扑 (Pounce / Dive)
- **Purpose**：位移 + 空中进攻 + 地形穿越（银河城关键移动技）
- **Player Fantasy**：猫的爆发扑咬
- **Input**：跳跃中按攻击 = 下扑；冲刺键 = 水平扑袭
- **Output**：快速突进/下扎，命中造成伤害并给短暂 i-frame；踩敌人可无限弹跳（pogo）
- **Success Condition**：扑袭是"赶路 + 进攻"合一，玩家爱用
- **Failure State**：i-frame 过长变无敌帧滥用；或后摇过长在平台跳跃时摔死
- **Edge Cases**：
  - 扑袭中撞墙 → 立即结束动作并短暂硬直（防卡墙）
  - 无敌人可踩的空旷深渊 → 下扑无弹跳，正常落地
- **Tuning Levers**：扑袭距离、i-frame 时长、硬直帧、弹跳高度
- **Dependencies**：爪击、地形碰撞、部分能力门（需扑袭过的窄缝）

### 4.3 折耳听声 (Fold-Ear Listening) — 招牌机制
- **Purpose**：把"猫的听觉"做成探索/解谜核心技，替代空洞骑士的"世界感知/梦境钉"定位，强化角色认同
- **Player Fantasy**：折耳一竖，听见墙后、地下、隐形的东西
- **Input**：长按听声键 → 波比折耳竖起，画面轻微降速 + 周遭泛起声波纹
- **Output**：
  - 显形隐藏平台 / 暗道 / 隐形敌人轮廓
  - 揭示"记忆残响"（叙事碎片，P2 支柱）
  - 标记附近灵毛富集点
- **Success Condition**：玩家养成"到岔路先听一声"的习惯；解谜靠听而非撞墙
- **Failure State**：听声无代价 → 玩家一直开着变成透视外挂；或太弱 → 没人用
- **Edge Cases**：
  - 听声中受击 → 立即打断并进入受击硬直（代价）
  - 寂瘴浓区 → 听声范围被压制（需先清瘴）
- **Tuning Levers**：听声时长阈值（多久才显形）、显形半径、受击打断规则、浓瘴衰减
- **Dependencies**：隐藏几何、叙事碎片系统、寂瘴系统

### 4.4 灵毛与灵影 (Spirit Motes & Shade)
- **Purpose**：局内资源（施法 + 死亡风险），元进度肉鸽的"风险载体"
- **Player Fantasy**：越敢打越有毛，但死了一地毛得自己捡回来
- **Input**：爪击命中自动累积；在猫窝消耗小鱼干治愈时也可转灵毛
- **Output**：灵毛池充盈 → 可放"猫之技艺"（法术）；死亡时未消耗的灵毛化为"灵影"留在死亡点
- **Success Condition**：玩家愿意冒险多攒毛放大招，也怕死丢毛而权衡
- **Failure State**：
  - 灵影太强/太远 → 回收变成劝退
  - 灵影无敌/卡地形 → 永久卡死（经济死锁）
- **Edge Cases**：
  - 在灵影处再次死亡 → 旧灵影被新灵影吸收，毛量叠加（防止无限丢毛循环）
  - 灵影卡在不可达点 → 提供"猫窝赎罪"花费小鱼干远程回收（兜底，防死锁）
- **Tuning Levers**：每击/每杀产毛量、池上限、灵影强度曲线、赎罪价
- **Dependencies**：所有法术、治愈、死亡重生

### 4.5 猫窝 / 长椅 (Cat Bed)
- **Purpose**：存档、回血、重组锚点，元进度肉鸽的"家"
- **Player Fantasy**：蜷进软垫，安全感
- **Input**：互动键
- **Output**：存进度、花小鱼干回满鱼心、可选"重组邻近挑战区"
- **Success Condition**：玩家把窝当决策点（"我先回窝存钱再冲"）
- **Failure State**：窝太多 → 无风险；窝太少 → 挫败
- **Edge Cases**：Boss  Arena 内禁窝；浓瘴区暂不可安窝
- **Tuning Levers**：窝密度、回血价、重组规则
- **Dependencies**：存档、经济、区域重组

### 4.6 项圈系统 (Collars — 符文替代)
- **Purpose**：build 多样性，风险换奖励的具象化（P5）
- **Player Fantasy**：给猫戴不同项圈，玩出不同流派
- **Input**：菜单装备，占用"项圈槽位 (Notches)"
- **Output**：修改伤害/资源/生存等维度
- **示例项圈**：
  - 利爪项圈：爪伤 +1，但最大鱼心 -1（攻防置换）
  - 静默项圈：听声显形更快、范围 +，但产毛 -15%
  - 贪吃项圈：小鱼干掉率 +25%，灵毛 -10%
  - 九命项圈：每次休窝后首次死亡原地复活一次（强但占 2 槽）
  - 绒盾项圈：完美格挡窗口 +50%
- **Success Condition**：玩家为不同区域换装；无"唯一最优解"
- **Failure State**：某项圈碾压其它 → 单调；槽位过多 → 无取舍
- **Edge Cases**：互斥项圈（同时戴冲突项圈 → 后者无效并提示）
- **Tuning Levers**：槽位数、各项圈数值、互斥规则
- **Dependencies**：全部战斗数值、听声、格挡

### 4.7 寂瘴 (Silence Blight)
- **Purpose**：环境危险 + 叙事载体（文明之死因），也是区域难度调节器
- **Player Fantasy**：踩进瘴里皮肤发麻，得赶紧出来
- **Input**：进入瘴区自动持续掉鱼心（可戴项圈减伤）
- **Output**：瘴区压制听声、增强敌人；清瘴点可临时净化
- **Success Condition**：瘴是"要不要冒险穿过去"的抉择，不是纯恶心
- **Failure State**：瘴太疼 → 绕路党；太弱 → 无意义
- **Edge Cases**：瘴中死亡 → 灵影生成在瘴外缘（防不可达）
- **Tuning Levers**：每秒掉血量、减听声系数、清瘴点密度
- **Dependencies**：听声、敌人增益、死亡

### 4.8 记忆绒毛 (Memory Fluff) — 元货币
- **Purpose**：Boss / 里程碑掉落的永久货币，驱动元进度树（P3）
- **Player Fantasy**：每次掀翻一个猫神，捡到它的一缕记忆
- **Input**：击败 Boss / 完成区域 100% 探索
- **Output**：在"猫神祭坛"解锁永久能力（新移动技、项圈槽 +1、灵毛池上限 +）
- **Success Condition**：元升级明显改变玩法但不破坏平衡
- **Failure State**：元升级过强 → 后期无挑战；过弱 → 没动力
- **Edge Cases**：重复 Boss（重组周目）→ 二次不掉绒毛，改掉小鱼干
- **Tuning Levers**：每 Boss 绒毛量、祭坛解锁价、上限
- **Dependencies**：Boss、元进度树

## 5. 经济与平衡 (Economy & Balance)

### 5.1 货币三层模型
| 货币 | 性质 | 来源 | 消耗 | 死亡处理 |
|------|------|------|------|----------|
| **灵毛 (Motes)** | 局内资源 | 爪击命中/击杀 | 放猫之技艺、窝内治愈 | 掉落为灵影，需回收 |
| **小鱼干 (Dried Fish)** | 金钱（永久） | 敌人/破坏物/探索 | 回血、买项圈/地图/升级 | **保留**（不丢） |
| **记忆绒毛 (Fluff)** | 元货币（永久） | Boss/里程碑 | 祭坛元升级 | 保留 |

> 设计意图：小鱼干永久保留 → 死亡挫败感被稀释（P3）；灵毛是真实风险（P3/P5）；绒毛是长期目标。

### 5.3 经济"崩溃"定义（先定义坏结果，才能认出它）
- **灵毛死锁**：灵影卡不可达且赎罪价过高 → 玩家永远缺毛放不出技 → **兜底：猫窝远程赎罪**
- **小鱼干通胀**：单位活跃玩家日均小鱼干增速 > 阈值 `[PLACEHOLDER 待定，建议 15%]` → 触发平衡 pass（调掉落/调物价）
- **唯一最优项圈**：某项圈胜率/使用率 > 70% 且其它 <10% → 该项圈需削或他人需补
- **元升级破环**：后期 Boss 被元升级碾压（击杀时长 < 20s）→ 需加 Boss 阶段或限元等级

## 6. 新手引导 (Onboarding)

- [x] **30 秒内给出核心动词**：开场即控制波比走路+爪击一只"看似玩具"的伪敌（反差萌 P4），必中，零失败
- [x] **教程第一段零死亡**：初始房间无真伤敌人，随意练爪击/扑袭
- [x] **低代价引入每个新机制**：听声先在"明显有暗道"处引导；下扑先在浅坑教学
- [x] **至少一个机制靠探索发现**：首个隐藏小鱼干堆不靠文字，靠玩家乱扑发现
- [x] **首局结尾留钩子**：第一次回窝后，远处传来猫神低吼 + 地图点亮新区域 → "再走一步"冲动
- [x] 首次死亡由灵影教学引导（绒毛巢「记忆残响」安全模拟死亡 → 生成灵影 → 爪击回收，引导第6项；战斗区死亡亦显示柔化层）

## 7. 进度曲线与 Boss 节奏（骨架）

```
区域1 绒毛巢 (教学)      → 小Boss: 锈齿鼠王      → 解锁: 折耳听声
区域2 沉眠回廊           → 小Boss: 眠蛛母        → 解锁: 二段扑
区域3 寂瘴沼             → Boss: 瘴喉            → 记忆绒毛×1
区域4 猫神殿 (重组挑战)  → Boss: 堕神·绒焰       → 记忆绒毛×1
终局 寂灭之眼            → 最终Boss: 沉眠之主     → 结局分支
```
> 重组仅发生在区域4及周常"寂瘴潮"；主探索区固定以保证地图记忆（P2）。

## 8. Fun Hypothesis & 已知假设

- **Fun Hypothesis（最重要的一条）**：*"小猫用听声找出暗道、扑进去一爪秒掉看似恐怖的敌人、再蜷回猫窝"这一连串循环本身就好玩*。若这条不成立，先修它，再谈其它。
- **已知假设（需验证/可能推翻）**：
  1. 假设平均单局 15–25 分钟（影响区域密度与窝间距）
  2. 假设玩家接受"死亡丢灵毛"作为唯一硬惩罚（若劝退率高，改灵影强度）
  3. 假设折耳听声不会被做成透视外挂（靠"受击打断 + 浓瘴压制"双锁）
  4. 肉鸽重组仅限挑战区，主世界固定——若玩家嫌主世界重复，再扩重组范围
