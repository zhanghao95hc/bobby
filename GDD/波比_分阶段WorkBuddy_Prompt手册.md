# 波比 (BOBBY) 分阶段 WorkBuddy Prompt 手册

> 配套文档：`D:/Project_WorkBuddy/Bobby/GDD/波比_Bobby_GDD_v0.1.md`  
> 用途：每个开发阶段，把对应区块里的 **「发送给 WorkBuddy 的 Prompt」** 直接复制粘贴进 WorkBuddy 会话即可。  
> 版本：v0.1（与 GDD v0.1 对应）

---

## 使用说明

1. **引擎前提（先定，后面所有 prompt 都依赖它）**  
   默认假设用 **HTML5 + Phaser 3（JavaScript）**，因为 WorkBuddy 能直接跑起来并在内置预览里看。  
   若你更想要桌面端，可在阶段 1 的 prompt 里改成 **Godot 4 (GDScript)** 或 **Unity (C#)**——后面 prompt 里的"实现"部分 WorkBuddy 会自动按引擎调整。
2. **每个 prompt 自带上下文**，可独立粘贴，不依赖前面聊过什么。但建议**一次只推进 1–2 个阶段，跑通再进下一个**，避免半成品堆积。
3. prompt 里出现的数值（如 HP=5、灵毛池=33）都是 GDD 里的 `[PLACEHOLDER]` 初值，WorkBuddy 跑出来后你按手感改，改完回写 GDD 的平衡表。
4. 每个阶段都给了**验收标准**——WorkBuddy 交付后你照着勾，不过就让它改。

## 阶段 1：引擎与项目骨架

**目标**：搭出能运行空场景的游戏工程，定好目录规范，后续阶段都往里填。  
**前置依赖**：无

**发送给 WorkBuddy 的 Prompt**：

```
你是波比(BOBBY)这个 2D 银河恶魔城肉鸽游戏的开发助手。请先帮我搭项目骨架。
参考 GDD：D:/Project_WorkBuddy/Bobby/GDD/波比_Bobby_GDD_v0.1.md
要求：
1. 引擎用 HTML5 + Phaser 3（若你判断不合适可提议替代，但默认 Phaser 3）。
2. 建好目录结构：src/(scenes, entities, systems, ui), assets/(sprites, audio, tiles), data/(balance.json)。
3. 跑通一个空场景：黑色背景 + 一个可移动的占位方块（代表波比），方向键/WASD 移动，能看到 FPS 和坐标。
4. 把 GDD 里"平衡表"的初值（玩家HP=5、灵毛池=33 等）先写进 data/balance.json，作为后续读取源。
5. 给出本地启动命令，并确保能在浏览器预览。
交付：可运行的工程 + 启动说明 + 目录树。
```

**验收标准**：浏览器能开、方块能移动、balance.json 存在且含 GDD 初值。

## 阶段 2：玩家控制器与核心手感

**目标**：波比的移动、爪击、扑袭手感达标——这是整局的"好玩"根基。  
**前置依赖**：阶段 1

**发送给 WorkBuddy 的 Prompt**：

```
基于阶段1的工程和 GDD 第4.1/4.2节，实现波比玩家控制器。
参考 GDD：D:/Project_WorkBuddy/Bobby/GDD/波比_Bobby_GDD_v0.1.md
实现：
1. 移动：左右走、跳、短按攻击=地面横扫爪击、空中按攻击=下扑(dive)。
2. 扑袭：跳跃中水平扑袭，命中给短暂 i-frame（初值0.3s，[PLACEHOLDER]）；空中下扑踩敌人可 pogo 弹跳（弹跳高度初值1.2x）。
3. 爪击：前方扇形伤害，初值1伤害单位，命中生成"灵毛+1"的飘字反馈（先只做反馈，灵毛系统阶段5接）。
4. 手感优先：调攻击前摇/后摇帧，让连击不卡顿；加极轻屏震和"噗"音占位。
5. 所有数值从 data/balance.json 读取，不要硬编码。
交付：可操控波比，爪击/扑袭/弹跳手感顺；附一段你对手感的说明（哪里还生硬）。
```

**验收标准**：能走跳、能爪击、能 pogo 弹跳；数值在 balance.json；你亲手试玩觉得"脆快有反馈"。

## 阶段 3：折耳听声（招牌机制）

**目标**：把"猫的听觉"做成探索/解谜核心技，并用双锁防透视外挂。  
**前置依赖**：阶段 2

**发送给 WorkBuddy 的 Prompt**：

```
实现 GDD 第4.3节「折耳听声」招牌机制。
参考 GDD：D:/Project_WorkBuddy/Bobby/GDD/波比_Bobby_GDD_v0.1.md
实现：
1. 长按听声键 → 波比折耳竖起，画面轻微降速+周遭泛声波纹。
2. 显形：隐藏平台/暗道/隐形敌人轮廓（初值显形阈值0.6s、半径6m，[PLACEHOLDER]）。
3. 双锁防透视：①听声中受击立即打断并进入受击硬直；②浓瘴区压制听声范围（浓瘴阶段7再做，先留接口）。
4. 放一个测试房：含1个隐藏暗道+1个隐形敌人，验证听声能找出。
交付：可触发听声、能显形隐藏物；写清双锁如何防止变透视外挂。
```

**验收标准**：长按能显形、受击会打断、测试房能靠听声通关。

**目标**：30 秒给出核心动词、零死亡教学、反差萌第一击。  
**前置依赖**：阶段 2、3

**发送给 WorkBuddy 的 Prompt**：

```

2. 教程第一段无真伤敌人，随意练爪击/扑袭/听声。
3. 至少一个机制靠探索发现：首个隐藏小鱼干堆不靠文字，靠玩家乱扑发现。
```

## 阶段 5：敌人框架 + 灵毛/灵影死亡循环

**目标**：敌人受击/死亡、灵毛积累、死亡掉落灵影与回收闭环。  
**前置依赖**：阶段 2、4

**发送给 WorkBuddy 的 Prompt**：

```
实现 GDD 第4.4节「灵毛与灵影」+ 基础敌人框架。
参考 GDD：D:/Project_WorkBuddy/Bobby/GDD/波比_Bobby_GDD_v0.1.md
实现：
1. 敌人：1种小怪（有HP、受击硬直、死亡掉小鱼干+产灵毛）。爪击命中自动累积灵毛（每击+1、每杀+3，[PLACEHOLDER]，读 balance.json）。
2. 灵毛池上限初值33；池满不再累积。
3. 死亡循环：玩家死亡 → 在死亡点生成"灵影"携带未消耗灵毛；回猫窝(阶段6)重生；回去击杀灵影回收灵毛。
4. 防死锁：①再次死亡时旧灵影被新灵影吸收(毛量叠加)；②灵影卡不可达时提供"猫窝远程赎罪"接口(阶段6接)。
5. 灵影强度初值占生前70%（[PLACEHOLDER]）。
交付：能打怪攒毛、能死、能回收；写出死锁兜底逻辑。
```

**验收标准**：打怪有毛、死有影、回收成功；模拟"死在坑里"不卡死。
